# WeBond: คู่มือเริ่มต้นสำหรับคนที่ไม่รู้อะไรเลย

คู่มือนี้พาคุณรัน WeBond บนเครื่องตัวเองตั้งแต่ศูนย์ ทำตามทีละขั้นและคัดลอกคำสั่งไปวางได้เลย
ถ้าจะเอาขึ้น AWS ดู [DEPLOYMENT.md](DEPLOYMENT.md) หลังจากรันในเครื่องได้แล้ว

> ทดสอบจริงบน macOS ส่วน Windows/Linux ยังไม่ได้ทดสอบ (คำสั่ง Docker เหมือนกัน แต่สคริปต์ `.sh`
> บน Windows ต้องรันใน Git Bash หรือ WSL)

---

## 0. WeBond คืออะไร

เว็บแอปลงทุนแบบง่าย ซื้อขาย **พันธบัตร กองทุนรวม และทองคำ** ในพอร์ตเดียว มีกระเป๋าเงิน
แผนลงทุนอัตโนมัติ (DCA) ประวัติรายการ และแดชบอร์ด ทุกอย่างเป็น **ข้อมูลสาธิต ไม่ใช่เงินจริง**

| ชิ้นส่วน | คืออะไร | อยู่ที่ไหน |
|----------|---------|-----------|
| **web** | หน้าเว็บที่เห็นในเบราว์เซอร์ | โฟลเดอร์ `web/` |
| **api** | โปรแกรมหลังบ้าน คิดเลขและเก็บข้อมูล | โฟลเดอร์ `api/` |
| **MySQL** | ฐานข้อมูล | รันใน Docker |

## 1. เลือกว่าจะทำแบบไหน

| | เส้นทาง A: ดูหน้าตาอย่างเดียว | เส้นทาง B: ระบบเต็ม (แนะนำ) |

## 2. เตรียมเครื่อง

### 2.1 เปิด Terminal

Terminal คือหน้าต่างพิมพ์คำสั่ง บน Mac กด `Cmd + Space` พิมพ์ `Terminal` แล้วกด Enter

### 2.2 ดาวน์โหลดโปรเจกต์แล้วเข้าไปในโฟลเดอร์

ถ้ายังไม่มีโปรเจกต์ในเครื่อง ให้ดาวน์โหลดจาก GitHub (ต้องติดตั้ง Git ก่อน macOS ลองพิมพ์ `git --version` ถ้ายังไม่มีเครื่องจะชวนติดตั้งให้):

```bash
git clone https://github.com/shivadeedev-hash/webond_aidlc.git
cd webond_aidlc
```

ถ้ามีโฟลเดอร์อยู่แล้ว (เช่นได้เป็นไฟล์ zip) ให้เข้าไปที่โฟลเดอร์นั้นแทน ปรับ path ให้ตรงกับเครื่องคุณ:

```bash
cd ~/Desktop/WeBond
```

ทุกคำสั่งในคู่มือนี้รันจากโฟลเดอร์นี้ เว้นแต่จะบอกให้ `cd` ไปที่อื่น
เช็คด้วย `ls` ต้องเห็น `web`, `api`, `scripts`, `docker-compose.yml`

### 2.3 Node.js (เส้นทาง A)

```bash
node -v
```

ถ้าขึ้นเลขเวอร์ชัน 20 ขึ้นไปก็ใช้ได้ ถ้าไม่มีให้ติดตั้งรุ่น LTS จาก <https://nodejs.org> แล้วเปิด Terminal ใหม่

### 2.4 Docker Desktop (เส้นทาง B)

1. ติดตั้งจาก <https://www.docker.com/products/docker-desktop/>
   (หรือถ้ามี Homebrew: `brew install --cask docker-desktop` ระบบจะถามรหัสผ่านเครื่อง)
2. **เปิดแอป Docker Desktop หนึ่งครั้ง** กดยอมรับเงื่อนไข แล้วรอจนสถานะเป็น "running"
3. เช็ค:

```bash
docker ps
```

ขึ้นตาราง (แม้จะว่าง) = พร้อม ถ้าขึ้น `Cannot connect to the Docker daemon` แปลว่ายังไม่ได้เปิดแอป

## 4. เส้นทาง B: ระบบเต็ม

### 4.1 เปิดทุกอย่างด้วยคำสั่งเดียว

```bash
./scripts/dev-up.sh
```

สคริปต์จะ:
1. ตรวจว่า Docker เปิดอยู่
2. สร้างไฟล์ตั้งค่า `.env` พร้อมรหัสลับแบบสุ่มให้เอง (ครั้งแรกเท่านั้น)
3. build และเปิด MySQL, API และหน้าเว็บ (ครั้งแรกใช้เวลาหลายนาที)
4. API **สร้างตารางในฐานข้อมูลและใส่ข้อมูลสาธิตให้เอง**
5. รอจนทุกอย่างพร้อม แล้วพิมพ์ที่อยู่และบัญชีสาธิตออกมา

เมื่อขึ้นว่า `WeBond is running.` ให้เปิด <http://localhost:5173> แล้วล็อกอิน

### 4.2 ทำให้ราคาเคลื่อนไหว (ต้องทำถ้าจะซื้อขายทองคำ)

ระบบอนุญาตให้ซื้อขายทองด้วยราคาที่อายุไม่เกิน 5 นาทีเท่านั้น ตัวสร้างราคาจำลองปิดอยู่เป็นค่าเริ่มต้น
ดังนั้นหลังเปิดระบบไม่กี่นาที หน้าทองคำจะขึ้นว่าราคาไม่พร้อม เปิดตัวสร้างราคาด้วย:

```bash
./scripts/live-prices.sh on
```

ราคาจะขยับทุก 60 วินาที และยังเปิดอยู่แม้รีสตาร์ท ปิดด้วย `./scripts/live-prices.sh off`

### 4.3 ลองเล่นอะไรดี

- **ตลาด**: ดูกองทุน พันธบัตร ทอง กราฟราคา และผลตอบแทนย้อนหลัง
- **ซื้อขาย**: พิมพ์จำนวนได้ตามสะดวก (`1,000` หรือ `฿1000` ก็ได้ ระบบใส่จุลภาคให้ ไม่รับเครื่องหมายลบ)
  หรือกดปุ่มจำนวนด่วน (ขั้นต่ำ / 1,000 / 5,000 / ทั้งหมด) ตอน **ขาย** จะเห็นว่าถืออยู่เท่าไร เลือกขายเป็นเงินบาทหรือเป็นหน่วย (ทองเป็นกรัม)
  และกด 25% / 50% / ทั้งหมดได้ ถ้ากรอกผิด จะบอกชัดๆ ว่าผิดเพราะอะไร (ต่ำกว่าขั้นต่ำ เกินเงินสด ไม่ใช่ทวีคูณของล็อต เกินที่ถืออยู่)
  ถ้าสินทรัพย์เสี่ยงเกินระดับของคุณ ระบบให้ติ๊กยอมรับก่อน ทองคำจะล็อกราคาให้ 30 วินาทีก่อนยืนยัน
- **พอร์ตโฟลิโอ / แดชบอร์ด**: มูลค่า กำไรขาดทุน สัดส่วนสินทรัพย์ เหตุการณ์ที่จะมาถึง
- **แผน DCA**: สร้างแผนลงทุนประจำสำหรับกองทุนหรือทอง
- **ประวัติ**: กรอง ค้นหา ดูสถานะ ยกเลิกรายการที่ยังรอ **ส่งออก Excel** และ **ดาวน์โหลดใบแจ้งยอด PDF**
  (เลือกเดือน ข้อมูลสาธิตส่วนใหญ่อยู่ที่ "ตุลาคม 2026")
- **โปรไฟล์**: แก้ชื่อ เบอร์ บัญชีธนาคาร ทำแบบประเมินความเสี่ยงใหม่ ฝาก/ถอนเงินสมมติ

กด F5 ได้ตามปกติ ยังล็อกอินอยู่ (ระบบจำเซสชันด้วย cookie ที่สคริปต์อ่านไม่ได้)

### 4.4 อีเมล (สมัครสมาชิก ยืนยันอีเมล ลืมรหัสผ่าน)

ระบบส่งอีเมลจริงผ่าน SMTP ฟรีทั้งหมด มี 2 แบบ

**แบบ 1 (ค่าเริ่มต้น ไม่ต้องตั้งอะไร): กล่องจดหมายในเครื่อง Mailpit**

อีเมลทุกฉบับไปอยู่ที่ <http://localhost:8025> ไม่ออกจากเครื่องคุณ ลองได้เลย:

1. เปิด <http://localhost:5173/register> แล้วสมัครด้วยอีเมลอะไรก็ได้ (เช่น `me@example.com`)
2. เปิด <http://localhost:8025> จะเห็นอีเมล "WeBond: รหัสยืนยันอีเมล" ที่มี **รหัส 6 หลัก**
3. กรอกรหัสในหน้า "ยืนยันอีเมล" (อีเมลถูกกรอกไว้ให้แล้ว) บัญชีจะเปิดใช้งาน แล้วล็อกอินได้
   อ่านอีเมลจากมือถือแล้วพิมพ์รหัสในคอมพิวเตอร์ก็ได้ เพราะเป็นรหัส ไม่ใช่ลิงก์
4. "ลืมรหัสผ่าน" ทำงานแบบเดียวกัน: ได้รหัส 6 หลักทางอีเมล แล้วตั้งรหัสผ่านใหม่

กติกาของรหัส: ใช้ได้ 15 นาที ใช้ได้ครั้งเดียว กรอกผิดได้ 5 ครั้ง ขอรหัสใหม่ได้ทุก 60 วินาที (ปุ่ม "ส่งรหัสใหม่") รหัสใหม่ทำให้รหัสเก่าใช้ไม่ได้

**แบบ 2: ส่งเข้ากล่องจริงด้วย Gmail (ฟรี ประมาณ 500 ฉบับต่อวัน ไม่ต้องมีโดเมน)**

1. เปิด 2-Step Verification ในบัญชี Google
2. สร้าง App password ที่ <https://myaccount.google.com/apppasswords> จะได้รหัส 16 ตัวอักษร
3. เพิ่มในไฟล์ `.env` (ใส่รหัสแบบไม่มีช่องว่าง ห้าม commit ไฟล์นี้):
   ```bash
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=465
   SMTP_USERNAME=your.name@gmail.com
   SMTP_PASSWORD=abcdefghijklmnop
   ```
4. รัน `./scripts/dev-up.sh` ใหม่ แล้วดูว่า `docker compose logs api` มีบรรทัด `e-mail delivery enabled`
   และ `smtpHost=smtp.gmail.com`

อีเมลจะออกจากชื่อ Gmail ของคุณ ถ้าไม่เห็นให้ดูในโฟลเดอร์สแปม อีเมลของบัญชีสาธิต
(`@webond.test`) ส่งเข้ากล่องจริงไม่ได้เพราะเป็นโดเมนสมมติ ลบ 4 บรรทัดนี้ออกเพื่อกลับไปใช้ Mailpit

## 5. ปิดและเปิดใหม่วันหลัง

| อยากทำ | คำสั่ง |
|--------|-------|
| ปิด (ข้อมูลไม่หาย) | `docker compose stop` |
| เปิดอีกครั้ง | `./scripts/dev-up.sh --no-build` |
| เปิดหลังแก้โค้ด | `./scripts/dev-up.sh` |
| ดูบันทึกการทำงานของ API | `docker compose logs -f api` (ออกด้วย `Ctrl + C`) |
| **ล้างทุกอย่างแล้วเริ่มใหม่** | `docker compose down -v` แล้ว `./scripts/dev-up.sh` |

`down -v` **ลบข้อมูลทั้งหมดที่คุณทำไว้ถาวร** แล้วระบบจะใส่ข้อมูลสาธิตชุดเดิมให้ใหม่

ปิดแอป Docker Desktop ได้เมื่อไม่ใช้ เพื่อคืนทรัพยากรเครื่อง

## 6. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|-------|--------|---------|
| `The Docker daemon is not running` | ยังไม่ได้เปิด Docker Desktop | เปิดแอป รอจนขึ้น running แล้วรันใหม่ |
| `port is already allocated` (3306, 8080 หรือ 5173) | มีโปรแกรมอื่นใช้พอร์ตนั้น (เช่น MySQL ในเครื่อง หรือ `npm run dev` ที่ยังไม่ปิด) | ปิดโปรแกรมนั้น ดูว่าใครใช้ด้วย `lsof -i :3306` |
| `The API did not become ready` | API เริ่มไม่สำเร็จ | ดู `docker compose logs api` |
| ทองคำขึ้น "ราคาไม่พร้อม" | ราคาเก่าเกิน 5 นาที (ตั้งใจให้เป็นแบบนี้) | `./scripts/live-prices.sh on` |
| ล็อกอินไม่ได้ | พิมพ์ผิด หรือผิด 5 ครั้งแล้วถูกล็อก 15 นาที | รอ 15 นาที หรือล้างข้อมูลด้วย `docker compose down -v` |
| ซื้อแล้วขึ้นว่าต้องทำแบบประเมินความเสี่ยง | บัญชีใหม่ยังไม่ได้ทำ | ไปที่โปรไฟล์ > ทำแบบประเมินความเสี่ยง |
| ใบแจ้งยอดไม่มีรายการ | เดือนที่เลือกไม่มีกิจกรรม | เลือก "ตุลาคม 2026" ที่มีข้อมูลสาธิต |
| ข้อมูลแปลกๆ หลังทดลองไปมาก | ข้อมูลที่ทำไว้สะสม | `docker compose down -v` แล้ว `./scripts/dev-up.sh` |
| ไม่ได้รับอีเมล | ยังใช้ Mailpit อยู่ หรือส่ง Gmail ไม่ผ่าน | ดูที่ <http://localhost:8025> ก่อน ถ้าตั้ง Gmail ไว้ ดู `docker compose logs api` หา `email delivery failed` (มักเป็น app password ผิด) ระบบลองส่งใหม่เองอีก 4 ครั้งภายในประมาณ 8 นาที |
| รหัสขึ้นว่า "หมดอายุ" หรือ "Too many wrong attempts" | รหัสใช้ได้ 15 นาที และกรอกผิดได้ 5 ครั้ง | กด "ส่งรหัสใหม่" แล้วใช้รหัสจากอีเมลฉบับล่าสุด |
| ล็อกอินแล้วขึ้นว่า "ยังไม่ได้ยืนยันอีเมล" | ยังไม่ได้กรอกรหัสยืนยัน | กด "ยืนยันอีเมลตอนนี้" ใต้ข้อความ |

## 7. สำหรับนักพัฒนา (ไม่บังคับ)

### 7.1 แก้หน้าเว็บแล้วเห็นผลทันที

container `web` ใช้พอร์ต 5173 อยู่ ให้หยุดมันก่อนแล้วรัน Vite เองในโหมด API:

```bash
docker compose stop web
cd web
npm install
VITE_DATA_SOURCE=api npm run dev
```

### 7.2 รันชุดทดสอบ

เทสต์ฝั่งเว็บไม่ต้องใช้ Docker:

```bash
cd web
npm run test
npm run lint
```

เทสต์ฝั่ง API ต้องมี Go (ใช้ `./scripts/setup-env.sh` ช่วยติดตั้งบน macOS) และ**ใช้ฐานข้อมูลแยก
`webond_test`** เทสต์จะไม่ยอมรันกับฐาน `webond` เพราะมันสร้างและลบข้อมูล:

```bash
./scripts/test-db.sh            # สร้างฐานทดสอบ (ครั้งแรก หรือ --reset เพื่อล้าง)
cd api
export WEBOND_TEST_DSN='webond:webond@tcp(127.0.0.1:3306)/webond_test?parseTime=true&loc=Asia%2FBangkok'
go test -tags=integration ./...
```

ข้อมูลสาธิตในฐาน `webond` จะไม่ถูกแตะ

- แอดมินสร้างข้อมูลหลักได้อย่างเดียว ยังแก้ไขหรือดูรายการผ่าน API แอดมินไม่ได้
- ใบแจ้งยอด PDF เป็นภาษาอังกฤษและใช้รหัสสินทรัพย์ (ฟอนต์มาตรฐานของ PDF แสดงภาษาไทยไม่ได้)
- เปลี่ยนรหัสผ่านแล้ว เซสชันที่ล็อกอินค้างไว้ในเครื่องอื่นยังใช้ได้จนหมดอายุ (สูงสุด 7 วัน)
- ทองคำไม่มีระดับความเสี่ยงในโครงสร้างข้อมูล ระบบจึงถือเป็นระดับ 1 (ต่ำสุด)
- คำสั่งซื้อขายที่สำเร็จหรือล้มเหลวยังไม่สร้างการแจ้งเตือนและอีเมล (การแจ้งเตือนของ DCA และคูปองพันธบัตรมีแล้ว)
- เวลาเปิดตลาด เวลาตัดรอบ และวันหยุด ใช้แค่เสาร์-อาทิตย์ ยังไม่รวมวันหยุดนักขัตฤกษ์

## 9. คำศัพท์สั้นๆ

| คำ | ความหมาย |
|----|----------|
| Terminal | หน้าต่างพิมพ์คำสั่ง |
| Docker / container | โปรแกรมที่รันซอฟต์แวร์ (เช่น MySQL) ในกล่องแยก ไม่ต้องติดตั้งลงเครื่องตรงๆ |
| API | โปรแกรมหลังบ้านที่หน้าเว็บเรียกขอข้อมูล |
| Migration | ชุดคำสั่งสร้างตารางในฐานข้อมูล (API ทำให้เอง) |
| Seed | ข้อมูลสาธิตที่ใส่ให้ตอนเริ่ม |
| Mock | ข้อมูลจำลองในไฟล์ ไม่ผ่านฐานข้อมูล |
| NAV | มูลค่าต่อหน่วยของกองทุนรวม |
| DCA | ลงทุนจำนวนเท่ากันเป็นงวดตามกำหนด |
| Clean price | ราคาพันธบัตรเป็น % ของราคาตราสาร (100 = เท่าราคาตราสาร 1,000 บาท) |
